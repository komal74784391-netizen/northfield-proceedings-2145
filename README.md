# Northfield Runtime Symposium 2027 - programme site

Static site source for the NRS 2027 programme.  Each item record in
`_proceedings/` is Markdown with YAML front matter.  The site is built from
this repository; edits here are the published source of truth.

Layout:

- `_config.yml` - site configuration
- `_proceedings/` - one Markdown record per programme item
